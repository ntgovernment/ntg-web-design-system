                  <p>
                    The Floating Call-to-Action (CTA) Button is a persistent,
                    visually prominent UI element designed to remain accessible
                    even when its original placement scrolls out of view.
                    Positioned typically at the bottom-right corner of the
                    viewport, this button ensures users can take key
                    actions—such as "Contact Us", "Book Now", or "Get
                    Started"—without needing to scroll back up or down.
                  </p>
                  <h2>Key Features</h2>
                  <ul>
                    <li>
                      Sticky Positioning: Automatically anchors to the viewport
                      once the original button location is no longer visible.
                    </li>
                    <li>
                      Responsive Design: Adapts to various screen sizes and
                      devices, maintaining usability across mobile, tablet, and
                      desktop.
                    </li>
                    <li>
                      Accessibility-Friendly: Includes proper ARIA labels and
                      keyboard navigation support.
                    </li>
                    <li>
                      Customizable Appearance: Supports theming, iconography,
                      and animation to match brand guidelines.
                    </li>
                    <li>
                      Smooth Transition: Uses subtle animations to transition
                      from static to floating state, enhancing user experience
                      without distraction.
                    </li>
                  </ul>
                  <h2>Use Cases</h2>
                  <ul>
                    <li>Persistent access to booking forms</li>
                    <li>Quick navigation to help or support</li>
                    <li>
                      Highlighting promotional actions or limited-time offers
                    </li>
                  </ul>
                  <h2>Design Considerations</h2>
                  <h3>Positioning</h3>
                  <ul>
                    <li>Usually bottom-right or bottom-center</li>
                    <li>Should not obstruct important content</li>
                    <li>Responsive to screen size (especially mobile)</li>
                  </ul>

                  <h3>Visibility</h3>
                  <ul>
                    <li>High contrast with background</li>
                    <li>Use of icons or labels for clarity</li>
                    <li>Optional animation when appearing/disappearing</li>
                  </ul>

                  <h3>Interaction</h3>
                  <ul>
                    <li>Click/tap triggers a modal, scroll, or navigation</li>
                    <li>
                      Should be keyboard-accessible and screen-reader friendly
                    </li>
                  </ul>

                  <h3>Behavior</h3>
                  <ul>
                    <li>
                      Can appear only after scrolling past a certain point
                    </li>
                    <li>May hide or change based on user interaction</li>
