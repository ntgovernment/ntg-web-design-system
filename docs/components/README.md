# Component Documentation

This folder holds example pages and documentation for each UI component provided by the design system. Developers and coding agents can browse these files locally or on the hosted site to understand usage, markup and behaviour.

## Available components

- accordion
- alerts
- callout
- display-cards
- document-cards
- featured-content-small
- floating-button
- hero-banners
- homepage-news
- image-gallery
- image-wrap (Markdown)
- minicards
- nav-block-with-description
- nav-block
- quick-exit
- topic-cards
- video

Each component now has a corresponding `.md` file in this directory that contains its documentation and example markup. Previously‑existing HTML examples have been consolidated into these markdown files and the duplicates removed. Agents can open the markdown directly; HTML is preserved inline when needed. The `image-wrap.md` file was already Markdown.
