# Component Documentation

This folder holds example pages and documentation for each UI component provided by the design system.  Developers and coding agents can browse these files locally or on the hosted site to understand usage, markup and behaviour.

## Available components

- accordion
- alerts
- callout
- display-cards
- document-cards
- featured-content-small
- floating-button
- hero-banners
- homepage-news
- image-gallery
- image-wrap (Markdown)
- minicards
- nav-block-with-description
- nav-block
- quick-exit
- topic-cards
- video

Each component has a corresponding file in this directory.  HTML files are standalone example pages demonstrating markup and styling; the `image-wrap.md` file is written in Markdown.
