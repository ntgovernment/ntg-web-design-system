Modern component — .ntg-image-wrap

Use .ntg-image-wrap with direction and size modifiers for inline images that wrap body text. On screens smaller than md the image stacks full-width above the text. Always close the wrapping content with <div class="ntg-content-clearfix"></div>.

Legacy classes — .content .imagehalf / .imagethird / .imagequarter

These classes are retained for backwards compatibility with existing Squiz Matrix CMS content. They no longer set left/right margins alone — pair them with Bootstrap's .float-start or .float-end utility to float the image. On small screens they expand to full width and the float is removed automatically.
